# Café SofIA · Tienda

Prototipo de la tienda de cara al cliente: catálogo con disponibilidad
real, carrito, pago por SINPE Móvil, identificación del cliente con
historial de compras, chat y voz con SofIA, y desafíos de café + IA.

Separado a propósito del tablero interno (`sofia-clase2-react`) — este
proyecto no muestra caja, ventas históricas, bitácora ni mensajes del
equipo. Usa el mismo backend real (Apps Script + Retell AI).

## Correrlo local

```
npm install
cp .env.example .env   # completar con los mismos valores que sofia-clase2-react
npm run dev
```
